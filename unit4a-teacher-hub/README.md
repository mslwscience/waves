## 🖼️ Classkick slides (4.04–4.14), 2026

Rebuilt to fill Classkick's visible View Work area: **2008 × 1580 px** (shown as 1004 × 790 on Classkick's 1004-wide canvas), so the whole slide shows without scrolling.

- `Unit4a_Waves_Classkick_2026_Welch_4.04-4.14_Slides_2008x1580.pdf` – all 45 slides, one per page, ready to import into Classkick.
- `png/` – the same slides as numbered PNGs.
- `scripts/` – Python + Playwright source. `lib.py` holds the shared layout; each `l4xx.py` builds one lesson group (run from inside `scripts/`). Two-page lessons are merged onto one slide automatically when they fit.

Requires: `pip install playwright beautifulsoup4 pillow img2pdf`.
